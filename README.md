# Sommi symbol library

The verified 20 November 2026 Library snapshot contains 5,782 Sommi symbols, 4,854 Sommi clothed symbols and 46,915 shared Sommi objects. The browser combines each figure collection with `library/objects`; Realistic uses that same objects directory. No extra objects copies are made for the three styles.

The current collections are `library/sommi`, `library/sommi-clothed`, and `library/objects`. Root-level legacy files remain for compatibility with existing published links. The website uses the immutable `library-2026-11-20` tag.

Images are unmodified copies of the finished Library WebPs, including their copyright metadata. Copyright Sensory App House Ltd; CC BY-NC 4.0. https://creativecommons.org/licenses/by-nc/4.0/

`library/SHA256.jsonl` lists every current image and its checksum.
